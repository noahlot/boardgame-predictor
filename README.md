# Board Game Predictor Model
by Noah Barajas and Jack Lawson for CSC 382 - Applied Machine Learning

To set up this project, make sure you have the following dependencies installed:
- Pandas
- NumPy
- scikit-learn
- MatPlotLib

These can be easily installed by running `pip install -r requirements.txt`

Main dataset sourced from [Board Games info from BoardGameGeek.com](https://www.kaggle.com/datasets/fotopoulosvasileios/board-games-info-from-boardgamegeek-com), in file `data_manipulation/bg_info.csv`
IDs sourced from [Board Game Database from BoardGameGeek.com](https://www.kaggle.com/datasets/threnjen/board-games-database-from-boardgamegeek?select=games.csv), in file `price_scraping/games.csv`
Additional pricing data sourced from [BoardGamePrices.com's JSON API](https://boardgameprices.com/api/plugin)
